# 设计规范文档 —— 电商自动化助手 · 管理后台
> 版本:v1.0 | 日期:2026-07-26 | 依据:docs/PRD.md v1.0
> 方向:浅色简洁专业风 · 蓝色主色 · 桌面优先(≥1280px),1024px 平板可用

## 1. 设计原则

1. **数据先于装饰**:界面为「快速读数、快速定位问题」服务,禁止无信息量的装饰元素
2. **状态一目了然**:商品状态、任务成败、设备在线与否,永远用「色点/标签 + 文字」双编码表达,不允许仅靠颜色区分
3. **危险操作有阻力**:删除、重置类操作必须二次确认,且确认按钮不可为默认焦点
4. **就地操作**:能用抽屉/行内编辑解决的,不跳转新页面,保持列表上下文
5. **一致胜过巧妙**:同类信息在所有页面使用同一组件与同一措辞

## 2. 视觉规范

> 开发时将本节全部落成 CSS 变量(design tokens),命名即下表 token 名。

### 2.1 色彩系统

**品牌色(蓝)**
| Token | 色值 | 用途 |
|-------|------|------|
| `--primary` | `#2a78d6` | 主按钮、链接、激活态、选中项 |
| `--primary-hover` | `#256abf` | 主按钮 hover |
| `--primary-active` | `#1c5cab` | 主按钮按下 |
| `--primary-bg` | `#ecf4fd` | 选中背景、浅色强调块 |

**中性色**
| Token | 色值 | 用途 |
|-------|------|------|
| `--bg-page` | `#f5f6f8` | 页面背景 |
| `--bg-card` | `#ffffff` | 卡片/表格/表单容器背景 |
| `--border` | `#e5e7eb` | 分割线、卡片描边 |
| `--text-primary` | `#1f2329` | 标题、正文 |
| `--text-secondary` | `#5f6672` | 辅助说明、表头 |
| `--text-muted` | `#9aa1ac` | 占位符、禁用文字 |

**语义色**(必须同时携带图标或文字,不得仅色块传义)
| Token | 色值 | 用途 |
|-------|------|------|
| `--success` | `#008300` | 发布成功、在线 |
| `--warning` | `#c98500` | 待处理、降级提醒(文字用深档保证对比度;色点可用 `#eda100`) |
| `--danger` | `#e34948` | 失败、删除、离线 |
| `--info` | `#2a78d6` | 进行中、提示 |

**图表色板**(已通过 CVD 校验,按槽位固定顺序取用、不得循环生成)
| 槽位 | 色值 | 说明 |
|------|------|------|
| series-1 | `#2a78d6` | 蓝(与品牌色同源;趋势图「采集」) |
| series-2 | `#eb6834` | 橙(趋势图「发布」) |
| series-3 | `#1baf7a` | 青绿 |
| series-4 | `#eda100` | 黄 |
| series-5 | `#e87ba4` | 玫红 |

图表硬性规则:≥2 个系列必须有图例;`#1baf7a / #eda100 / #e87ba4` 在浅色表面对比度不足 3:1,凡使用必须配**直接数值标签或表格视图**兜底;失败原因分布超过 5 类时,第 6 类起合并为「其他」;禁止双 Y 轴。

### 2.2 字体系统
| 层级 | 字号/行高 | 字重 | 用途 |
|------|-----------|------|------|
| H1 | 20px / 28px | 600 | 页面标题 |
| H2 | 16px / 24px | 600 | 卡片标题、分组标题 |
| Body | 14px / 22px | 400 | 正文、表格内容 |
| Caption | 12px / 20px | 400 | 辅助说明、表头、时间戳 |
| Metric | 28px / 36px | 600 | 看板指标数字(等宽数字 `font-variant-numeric: tabular-nums`) |

字体族:`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif`;代码/ID 类字段用 `ui-monospace, "SF Mono", Consolas, monospace`。

### 2.3 间距与圆角
- 间距基准 **4px**,常用档位:4 / 8 / 12 / 16 / 24 / 32
- 卡片内边距 24px;表单项垂直间距 24px;卡片之间 16px;页面左右留白 24px
- 圆角:卡片/弹窗 8px,按钮/输入框/标签 6px,色点 50%

### 2.4 阴影与层级
| 层级 | 阴影 | 用途 |
|------|------|------|
| 卡片 | `0 1px 2px rgba(31,35,41,.06)` | 静态容器(以描边为主,阴影极轻) |
| 抽屉/下拉 | `0 4px 16px rgba(31,35,41,.12)` | 浮层 |
| 弹窗 | `0 8px 32px rgba(31,35,41,.16)` | 模态框 + 半透明遮罩 `rgba(31,35,41,.45)` |

## 3. 组件规范

**按钮**(高 36px,内边距 16px,圆角 6px)
- 主按钮:`--primary` 底白字;hover/active 用对应 token;禁用 40% 透明
- 次按钮:白底 `--border` 描边 `--text-primary` 字
- 危险按钮:仅在确认弹窗内出现实底 `--danger`;列表中的删除入口用文字链形态
- 加载中:内嵌 spinner,文字保留,按钮禁点

**输入框**(高 36px)
- 默认 `--border` 描边;聚焦 `--primary` 描边 + 2px 同色 20% 外圈;错误 `--danger` 描边 + 下方 12px 红色错误文案
- API Key 类敏感字段:密码型输入 + 「显示」切换,回显仅末 4 位

**表格**
- 表头:`--bg-page` 底、Caption 级灰字;行高 48px;斑马纹不用,以 1px 行分割线代替
- hover 行背景 `#f8f9fb`;行内操作(编辑/删除)常驻右侧文字链,不做 hover 才出现
- 分页器右下,每页 20 条;列表必备三态:加载(骨架屏 5 行)/ 空(图标 + 一句话 + 引导按钮)/ 错误(说明 + 重试按钮)

**状态标签 Tag**(高 22px,圆角 6px,浅底深字 + 前置色点)
| 状态 | 样式 |
|------|------|
| 草稿 | 灰底灰字 |
| 待发布 | 蓝底(`--primary-bg`)蓝字 |
| 已发布/成功 | 绿底绿字 |
| 发布失败/失败 | 红底红字 |
| 进行中 | 蓝底蓝字 + 旋转图标 |

**弹窗与抽屉**
- 确认弹窗宽 420px:标题 + 说明 + 右下「取消(默认焦点)/ 确认」;删除确认需复述对象名称
- 详情/编辑抽屉:右侧滑入,宽 560px(商品编辑 640px);标题栏含关闭按钮;底部操作栏吸底

**侧边导航**
- 宽 220px,深灰白底(`#ffffff` + 右侧 1px 描边);选中项 `--primary-bg` 底 + `--primary` 左侧 3px 指示条 + 图标文字同色
- 顺序:数据看板 / 商品库 / 映射管理 / 任务日志 / 配置中心 / 成员管理(后两项仅管理员可见)

## 4. 页面原型

### 4.1 登录页
居中卡片 400px:Logo + 产品名 → 账号 → 密码 → 登录按钮(全宽)。错误在表单顶部红色条提示。无注册入口。

### 4.2 数据看板
```
┌─────────────────────────────────────────────────────────┐
│ 数据看板                                    [近7天▾]      │
├──────────┬──────────┬──────────┬──────────┐             │
│ 今日采集  │ 今日发布  │ 发布成功率│ 待处理失败│  ← 4 张指标卡 │
│   32     │   28     │  87.5%   │    4 ⚠   │   Metric 字号│
├──────────┴──────────┴──────────┴──────────┴─────────────┤
│ 采集与发布趋势(折线,series-1 采集 / series-2 发布)       │
│ [图例] [crosshair+tooltip]                    高度 320px  │
├───────────────────────────────┬─────────────────────────┤
│ 失败原因分布(横向条形,带数值) │ 最近失败任务 Top5 列表    │
└───────────────────────────────┴─────────────────────────┘
```
- 「待处理失败数」卡片 >0 时数字用 `--danger`,整卡可点击跳任务日志(带失败筛选)
- 趋势图两系列必带图例 + tooltip;失败原因条形图每条带直接数值标签

### 4.3 商品库(列表)
```
┌ 商品库 ────────────────────────────────────────────────┐
│ [状态筛选:全部|草稿|待发布|已发布|失败] [搜索框____] [批量▾]│
├─┬────────┬───────────────┬───────┬───────┬──────┬─────┤
│☑│ 主图    │ 标题(优化后)   │ 采集价 │ 售价  │ 状态  │ 操作 │
│ │ [64px] │ 两行截断…      │ ¥12.5 │ ¥19.9 │ 待发布│编辑 删除│
├─┴────────┴───────────────┴───────┴───────┴──────┴─────┤
│                                    ‹ 1 2 3 › 每页20条   │
└────────────────────────────────────────────────────────┘
```
点击行 → 右侧 640px 抽屉(详情/编辑合一):主图轮播 → 标题区(原标题灰字 + 3 个 AI 候选标题单选 + 自定义输入)→ 价格区(采集价只读、售价可编辑、加价规则提示)→ SKU 表格(规格/价格/库存行内编辑)→ 详情图缩略网格。底部吸底:「删除」(左,文字链)「保存」「保存并标记待发布」(右)。

### 4.4 映射管理
列表列:1688 商品(缩略图+标题)| 淘宝商品(标题/ID)| 加价规则快照 | 发布时间 | 操作(详情/删除)。
详情抽屉:上下两块商品信息卡 + SKU 对应关系表(1688 规格 ↔ 淘宝规格 ↔ 价格)+ 「查看原始采集数据」折叠 JSON。

### 4.6 配置中心(仅管理员)
左侧锚点分组、右侧表单卡片:加价规则(类型单选 + 数值 + 实时示例「采集价 ¥10 → 售价 ¥13」)/ AI 配置(模型单选 + API Key 密文输入 + 「测试连接」按钮)/ 发布默认项 / 操作速度(双滑块 300–3000ms)。每张卡片独立「保存」,保存成功 toast + 「已同步至 App」说明。

### 4.7 成员管理(仅管理员)
表格:账号 | 角色 Tag | 创建时间 | 操作(重置密码/删除)。右上「新建成员」弹窗:账号、初始密码、角色单选。不可删除自己。

## 5. 交互规范

- **反馈**:写操作成功用右上 toast(2.5s 自动消失);失败用 toast + 表单内具体错误;不可恢复操作前置确认弹窗
- **加载**:页面级用骨架屏;按钮级用内嵌 spinner;图表加载用容器内居中 spinner;所有请求超过 8s 显示「网络较慢」提示与取消
- **空状态**:图标 + 一句话说明 + 行动按钮(如商品库空 →「去手机端采集第一个商品」说明文案)
- **错误状态**:接口失败显示错误卡片 + 「重试」;401 全局跳登录并提示「登录已过期」
- **过渡**:抽屉滑入/弹窗淡入 200ms ease-out;不做页面切换动画;`prefers-reduced-motion` 时全部关闭
- **图表交互**:折线图 crosshair + 联合 tooltip;条形图逐条 hover tooltip;tooltip 内文字用文本色,系列色仅作前置色点
- **键盘/可访问性**:弹窗内焦点圈闭,Esc 关闭;表单 label 全绑定;色彩之外必有文字/图标传义

## 6. 响应式规则

| 断点 | 布局变化 |
|------|---------|
| ≥1280px | 标准布局:220px 侧边栏 + 内容区;看板指标卡 4 列 |
| 1024–1279px | 侧边栏收窄为 64px 图标栏(hover 展开);指标卡 2×2;看板下方两栏改上下堆叠 |
| <1024px | 一期不适配(显示「请使用桌面端访问」引导页);二期 H5 单独设计 |

表格在窄屏下容器内横向滚动,首列(主图/名称)吸附左侧。
