## 反馈原声

| # | 反馈 | 严重度 | 处理 |
|---|------|--------|------|
| 1 | 「登录进来全是数字报表,我是来上架商品的,第一步点哪?找遍首页没有一个"采集"或"上架"按钮。」 | 高 | ✅ 看板顶部新增可关闭的三步新手引导卡(连接 App → 采集 → 一键发布) |
| 2 | 「我在电脑上逛 1688 看中了货,想把链接丢进来就完事,结果整个后台没有"添加商品"入口,空状态才告诉我要去手机操作,太绕了。」 | 高 | ✅ 商品库新增「+ 采集 1688 商品」:粘贴链接 → 下发采集指令到手机 App,采集完成自动入库 |

## 结论
核心问题不是功能缺失,而是**用户的目标动词(采集、上架)在界面上没有对应的按钮**,以及**指令下发后的状态黑盒**。本轮改进后,主链路变为:粘贴链接采集 → 编辑确认 → 一键发布到千牛 → 任务日志跟踪进度,每一步都有明确的下一步指引。
